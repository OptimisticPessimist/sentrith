# Sentrith Language Policy

- `README.md` is the canonical English landing page.
- `README.ja.md` is the full Japanese landing page.
- `README.en.md` is kept only as a compatibility pointer.
- Both landing pages show `English ｜ 日本語` at the top with the active language emphasized.
- Brand assets are language-specific where text is embedded in the image.
- Detailed docs may remain Japanese-first until equivalent English docs exist; English README labels those links clearly rather than pretending full parity.

- Every `*.ja.md` detailed document must have a corresponding `*.en.md` file.
- English canonical README links should prefer English detail docs when available.
- Automated README publishers must write English to `README.md` and Japanese to `README.ja.md`; `README.en.md` is compatibility-only.
