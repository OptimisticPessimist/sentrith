# Sentrith Versioning

Sentrithの公開SemVerは **v1.0.0** から開始します。

Sentrith命名前に使われていた内部snapshot番号は公開releaseではありません。
それらをREADME、Quickstart、feature docs、workflow documentationのversion historyとして扱いません。

公開versionのsource of truth:

- Cargo package: `1.0.0`
- Git tag: `sentrith-v1.0.0`
- GitHub Release: `Sentrith v1.0.0`

将来の変更はSemVerに従います。
