# Meta Documentation

`docs/meta/` contains Sentrith's own philosophy, history, versioning, and maintenance rationale.

**Do not load this directory during ordinary feature, bug-fix, refactor, debugging, or repository-search work.**

It is not evidence about the application being built.

Contents include:

- `PHILOSOPHY.*.md`
- `HISTORY.*.md`
- `VERSIONING.md`
- `LANGUAGE_POLICY.md`

For current application architecture, use `docs/architecture/`.

For durable project decisions, use `docs/ai/DECISIONS.md`.
