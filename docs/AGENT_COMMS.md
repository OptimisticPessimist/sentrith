## ルール
- 作業開始時は、このファイルを確認する（リポジトリに HANDOFF 系のドキュメントがある場合はそちらも）。
- 残すべき履歴・判断・警告は、ここに**文章で**追記する（append-only）。git のチェックポイント参照（refs/codex/*）はいつ消えてもおかしくない前提で、そちらに依存しない。
- 各エントリには日付と署名（エージェント名＋モデル名）を付ける。
- 大きな生成物はコミットしない。
