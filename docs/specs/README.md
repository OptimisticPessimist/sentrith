# Feature Specifications

Create a feature directory only for work that benefits from a durable specification.

Recommended for Level 2 tasks:

```text
docs/specs/<feature>/
├── SPEC.md
├── PLAN.md
└── TASKS.md
```

Use the templates under `_templates/`.

Completed specifications may remain as durable product/engineering intent, but do not treat old `PLAN.md` or `TASKS.md` files as current project state.

Current operational state belongs in `docs/ai/STATE.md`.
